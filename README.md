## 🍯 Honeypot Server (2052 NEW)

The **HTTP Honeypot Server** clones a target website and serves it to attackers while logging all requests.

### Features

- **Website Cloning** — Downloads and inlines CSS, JS, and images
- **Full Request Logging** — Logs IP, port, user-agent, referer, path, POST data
- **Server Banner Spoofing** — Uses real server banner from target
- **Background Threading** — Runs alongside other scans
- **Twisted-based** — Fast, production-grade HTTP server

### Quick Start

```bash
# Deploy honeypot server on default port 8080
python3 finalrecon-ai.py --url https://target.com --start-honeypot-server

# Custom host & port
python3 finalrecon-ai.py --url https://target.com --start-honeypot-server \
  --hp-host 0.0.0.0 --hp-port 9090

# Standalone honeypot server (runs forever)
python3 finalrecon-ai.py --url https://target.com --honeypot-server --hp-port 8080

# Clone a different URL than target
python3 finalrecon-ai.py --url https://example.com --start-honeypot-server \
  --hp-url https://real-target.com
```

### Log File

All requests are logged to:

```
http_honeypot_2052.log
```

**Log format:**
```

language='en-US', referer='-', protocol='HTTP/1.1', path='/admin',
post_data={'username': ['admin'], 'password': ['123456']}
```
